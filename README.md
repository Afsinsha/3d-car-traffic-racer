🚗 3D Car Traffic Racer

A 3D traffic racing game built with the Godot game engine.

🎮 About the Game

Drive through traffic, overtake other vehicles, and earn in-game money for successful overtakes.

✨ Features

* 3D car racing gameplay
* Traffic overtaking mechanics
* In-game money rewards
* Main menu

🛠️ Built With

* Godot Engine
* GDScript

🎯 Objective

Overtake traffic and earn in-game money while driving.
